EAR_어지럼증

대표유형: 어지럼증(+)

  • case0: 한쪽으로만 쓰러지려고 한다.(+)
    • 진단은? → 소뇌경색 (중추성 현훈)
    • 검사는? → 뇌CT
  • case1: 자세변화에 악화(+) 안진(+)
    • 진단은? → 양성.돌발성.두위.현훈 (BPPV)
      • if: 후반고리관 vs 수평반고리관
        • if: 딕스-홀파이크에서(45도) 발생(+) → 고개를 돌린쪽 후반고리관
        • if: 누워머리돌림검사에서(90도) 발생(+) → 안진이 강한쪽 수평반고리관
      • if: Canalolithiasis(관내결석) vs Cupulolithiasis(마루결석)
        • if: <1분(+) → 관내결석
        • if: >1분(+) → 마루결석
    • 검사는? → Dix-Hallpike, 안진검사
    • 치료는? → 이석 정복
  • case2: 이충만감(+) 이명(+) 안진(-)
    • 진단은? → 메니에르
    • 검사는? → 순음청력검사
    • 치료는? → 저염식/이뇨제/디펜히드라민/벤조디아제핀
  • case3: 최근 감기(+) 안진(+)
    • 진단은? → 전정신경염
    • 치료는? → 전정재활

예시유형: 딕스-홀파이크 검사에서는 안진이 뚜렷이 보이지 않으나, 누워머리돌림검사(Supine head roll test)에서 우측으로 머리를 돌렸을 때 우측으로 안진이 발생하며, 좌측으로 머리를 돌렸을 때 좌측으로 안진이 발생한다. 안진은 머리를 우측으로 돌렸을 때 진폭이 더 컸다. 진단은? → 우측 수평반고리관양성돌발현훈, 관내결석(canalolithiasis)
