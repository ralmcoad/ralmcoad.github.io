2' 무월경

(본 문서에서는 난포자극/황체형성 호르몬이 감소되지 않은 2' 무월경에 대해서만 서술한다. 난/황이 감소된 2' 무월경에 대해서는 뇌하수체저하증 문서 참고)

대표유형: "28세가 3개월 동안 월경이 없어서/적어서 왔다." 베타사람융모생식샘자극호르몬(-)

  • if: 최근 중절/긁어냄술(+)
    • 검사는? → 자궁난관조영술 or 자궁경
      • if: 자궁내막유착(+)
        • 진단은? → 아셔만증후군
        • 치료는? → 자궁경 유착 절제술
  • if: 최근 중절/긁어냄술(-)
    • 검사는? → 난/황/갑/프
      • if: ↓난/황(-) ↑갑(-) ↑프(-)
        • 검사는? → 염색체검사[1] (극소수의 초경이 가능한 터너증후군을 배제)
          • if: 46,XX(+) ↑난/황(±)[2] 최근 항암치료(±)
            • 진단은? → 조기난소부전[3]
            • 치료는? → E+P (=복합경구피임약)
          • if: 46,XX(+) 여드름/다모증/다낭성난소(+)
            • 진단은? → 다낭성난소증후군

대표유형: 여드름/다모증/다낭성난소(+) ↑테스토스테론(±)

  • 진단은? → PCOS
  • 원인은? → E 지속노출로 인한 파탄성 출혈
  • if: "월경이 없어서 왔다."[4]
    • 치료는? → 복합경구피임약(E+P) or P
    • if: 흡연≥35세 or 유방암 or 심혈관질환[5]
      • 치료는? → 프로게스테론
  • if: "임신이 되지 않아서 왔다."
    • 치료는? → 레트로졸(방향화효소억제제) or 클로미펜(선택적 에스트로겐 수용체 조절제)
  • if: 자궁내막>14mm
    • 진단은? → 내막증식증 d/t PCOS
    • 검사는? → 내막생검

대표유형: 임신테스트기(+) 마지막월경시작일=6주전(+) 자궁에 임신낭(-)

  • if: hCG≥3000(+)
    • 진단은? → 자궁외임신 (이렇게 높으면 임신낭이 어딘가엔 무조건 있어야함)
  • else:
    • 진단은? → 임신 (임신낭은 6주부터 슬슬 보이기 시작함)
    • 치료는? → hCG 추적관찰

  1. All negative{자궁유착위험(-), 난/황(-), 갑/프(-)} 에서 진짜 최종으로 염색체검사를 해보고, 그도 아니면 조기난소부전으로 처리한다고 외우면 된다. (일종의 배제진단)↩︎

  2. 난소의 negative feedback 소실로 인해 난/황이 상승한다. 참고로 갑/프 borderline high(+) 난/황 high(+)를 줘놓고 답으로 조기난소부전을 골라야하는 기출도 있었다.↩︎

  3. 참고로 40세가 넘어가면 진단명은 "폐경"으로 바뀐다.↩︎

  4. 대부분의 문제에서 선지에 클로미펜과 프로게스테론이 공존한다. 주호소가 불임인지 무월경인지 잘 보고 선지를 골라야함.↩︎

  5. =복합경구피임약의 금기증↩︎
